# Asset credits

Everything in the tables under "CC0 assets" is CC0 (public domain): either downloaded from a CC0 source or made for this project by a tool in `tools/`. No attribution is required, but we list every source anyway. Paths are relative to `godot/assets/` unless they start with `godot/`.

These are not CC0, and each has its own section or row below:

- the Barlow and Chakra Petch fonts (SIL Open Font License 1.1);
- the add-ons in `godot/addons/` (MIT and Apache-2.0).

MPFB 2 (MakeHuman for Blender, GPL-3.0) is used only as a build tool by `tools/build_character_assets.py`; none of its code ships.
