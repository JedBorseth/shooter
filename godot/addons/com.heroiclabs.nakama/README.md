# nakama-godot

The Nakama client for Godot 4 by Heroic Labs, Apache License 2.0 (`LICENSE`),
from [heroiclabs/nakama-godot](https://github.com/heroiclabs/nakama-godot) at
commit `6dc7b3951d` (master after 3.4.0), unchanged.

Only the Nakama client is copied: the Satori client and the C# helpers are left
out. The game uses it through `res://scripts/online.gd`; see docs/online.md.
To update it, copy `addons/com.heroiclabs.nakama` from a newer commit over
these files, keeping this README and `LICENSE`.
